NB TECHNO - FREE WEBSITE

Files:
- index.html = main website
- logo.png = your supplied NB TECHNO logo

HOW TO PUBLISH FREE:
1. Create a free account at GitHub.
2. Create a new public repository named: nbtechno.github.io
3. Upload index.html and logo.png.
4. In repository Settings -> Pages, enable GitHub Pages from the main branch.
5. Your free website will be available at:
   https://nbtechno.github.io/

You can later connect a custom domain such as nbtechno.in if you purchase one.
